## 🚀 How to Run a Program

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the folder containing the C source file.
4. Compile the program using GCC:

   ```bash
   gcc PROGRAM_01.C -o PROGRAM_01
   ```

5. Run the compiled program.

   **Windows:**
   ```powershell
   .\PROGRAM_01.exe
   ```

   **Linux:**
   ```bash
   ./PROGRAM_01
   ```

Replace `PROGRAM_01.C` with the filename you want to run.
